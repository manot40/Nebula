# AGENTS.md — Nebula Developer Guide

**Nebula** is a Java 21 game server emulator built with Gradle (`8.14.7` wrapper), Javalin (HTTP + encrypted protobuf-over-HTTP game transport), Quickbuf protobufs, and Morphia/MongoDB (with an embedded `mongo-java-server` H2 fallback).

---

## Build & Verification Commands

```bash
# Build fat executable jar (Nebula.jar at repo root) — REQUIRED for clean compile
# Note: gradlew is not marked +x in git (CI runs `chmod +x gradlew` first)
bash ./gradlew jar

# Alternative compile-only check (still runs injectGitHash first)
bash ./gradlew injectGitHash compileJava

# Regenerate Quickbuf Java classes from ./proto/ (only if .proto files exist locally)
GENERATE_PROTO=true bash ./gradlew updateProto
```

- **Java version**: JDK 21 (`JavaLanguageVersion.of(21)` in `build.gradle`).
- **`BuildConfig.java` gotcha**: `src/main/java/emu/nebula/BuildConfig.java` is **gitignored** and generated by the `injectGitHash` Gradle task, which is attached to `jar` (not `compileJava`). Running `./gradlew compileJava` on a fresh clone fails unless `injectGitHash` or `jar` has run.
- **No test suite**: There is no `src/test/` directory. Verify changes with `./gradlew jar` and targeted runtime/packet checks.
- **Proto sources**: `.proto` files live in gitignored `/proto/`, while generated Quickbuf Java sources in `src/generated/main/emu/nebula/proto/` **are committed** to git. Do not run `./gradlew clean` with `GENERATE_PROTO=true` unless `/proto/` is populated, or it will delete `src/generated/`.

## Package Map (`src/main/java/emu/nebula/`)

| Package | Responsibility |
| :--- | :--- |
| `Nebula.java`, `Config.java`, `GameConstants.java`, `RegionConfig.java` | Boot entrypoint, JSON config (`./data/config.json`), constants, region/data versions |
| `server/` | Javalin `HttpServer`, `routes/` (login/SDK/meta/agent endpoints), `handlers/` (`@HandlerId` packet handlers), `error/` |
| `net/` | `GameSession`, `NetHandler`, `HandlerId`, `NetMsgId`, `PacketHelper` |
| `game/` | `GameContext` (1s tick + global `*Module`s), `player/` (`Player`, `PlayerManager`, `PlayerChangeInfo`), and domain packages (`character/`, `dorm/`, `gacha/`, `inventory/`, `quest/`, `tower/`, etc.) |
| `data/` | `ResourceLoader`, `GameData` (`DataTable<T>` registry), `BaseDef`, `ResourceType`, `resources/` (`*Def`), `custom/` (`*ParamDef`) |
| `database/` | `DatabaseManager` (Morphia + embedded Mongo/H2), `GameDatabaseObject`, `AccountDatabaseOnly`, fastutil BSON `codecs/` |
| `command/` | `CommandManager`, `@Command`, `CommandHandler`, `CommandArgs`, `commands/` |
| `plugin/` | `PluginManager`, `Plugin` lifecycle (`plugins/*.jar` + `plugin.json`) |
| `util/` | `AeadHelper`, `Handbook`, `JsonUtils`, `ResetCycle`, `Snowflake`, `Utils`, `ints/` |

## Critical Invariants

1. **Wire every new `PlayerManager` in two places**:
   - Load/init it inside `Player.onLoad()` (`src/main/java/emu/nebula/game/player/Player.java`).
   - Delete its MongoDB document/collection inside `PlayerModule.deletePlayer(int uid)` (`src/main/java/emu/nebula/game/player/PlayerModule.java`).
2. **Match `ResourceLoader` naming conventions**:
   - `ResourceLoader.getTableForResource()` strips `"Def"` and appends `"DataTable"` (e.g., `DormQuestDef` -> `GameData.DormQuestDataTable`).
   - External client tables load from `./resources/bin/<Name>.json`; server-only overrides/extensions use `useInternal = true` from `src/main/resources/defs/<Name>.json`.
3. **Respect database separation**:
   - Account-DB entities must be annotated with `@AccountDatabaseOnly`; all other `@Entity` classes map to the game database.
   - Always set `useDiscriminator = false` on `@Entity(value = "...", useDiscriminator = false)` and provide a no-arg constructor for Morphia.
4. **Use Quickbuf & `GameSession` packet helpers**:
   - Instantiate Quickbuf protos with `ProtoClass.newInstance()` (never `new ProtoClass()`).
   - Return responses via `session.encodeMsg(...)` so `PlayerChangeInfo` / `player.addNextPackage(...)` notifications are automatically chained and `session.afterResponse()` runs deferred saves.
5. **Keep runtime artifacts out of git**:
   - Never commit `Nebula.jar`, `BuildConfig.java`, `/data`, `/resources`, `/logs`, `/proto`, or `Nebula Handbook.txt`.
